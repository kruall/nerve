# Validation and forward-testing

Before installation, validate the exact complete `SKILL.md` with Nerve's shared validator (discovery or the create/update path). Confirm canonical metadata, SemVer, package/name match, dependency validity, and that resource paths and symlinks do not escape the package. Validate `agents/openai.yaml` when `codex` is enabled.

Forward-test realistic creation, evidence-backed amendment, revision with a current revision token, dependency composition, and the lockdown/config-PR path that applies. Preserve raw prompts, results, and validation output as proposal evidence. Never claim a test passed from an unexecuted plan.
